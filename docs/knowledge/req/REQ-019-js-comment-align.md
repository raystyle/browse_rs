# REQ-019：注释惰性化对齐全模板道

## Scenario

0.29.0 注释惰性化只落 rune 脚本模板道，评审 G-1 披露 `--js`/方言片段模板道与 js_lib 库渲染的注释仍参与渲染与未填键点名（战役台坑一在这两个面仍可复现）；总台令「继续」启动对齐批。

## Criteria

- [x] 三面同规：方言片段模板道、`--js` 小程序模板道（CLI `render_js_template`）、js_lib 库渲染（daemon 侧抽占位回填）
- [x] JS 族词法分叉：只抽注释、不认 r#；字符串（含单引号与模板串）照旧参与渲染；正则字面量感知（启发式前一显著字符/关键字后起正则、`\` 转义与 `[...]` 字符类吞 `/`）防正则内 `//` 误判
- [x] 未填键点名扫描不再看注释（三面一致）
- [x] 测试：JS 族单测三件＋CLI 渲染道一件＋e2e 真引擎一件＋全族回归

## Notes

- 词法族判据：r# 属 Rune 语法（Rune 族重写、JS 族不动）；正则字面量属 JS 语法（JS 族感知、Rune 族无此面）；注释两形两族同构
- 评审快核 F-1（必修已修）：占位与 Jinja 控制流冲突：subst 语义改为「0 次静默略过（区间被控制流丢弃）、出现即全量替换（循环体每次复制都回填）」，注入面由残留前缀检查兜；三面回归锁（client 双面真 Jinja 死分支/循环体 + js_lib e2e 扩展）
- 误判安全网（评审 G-1 措辞）：正则/除法启发式误判字节中性（extract 加 subst 恒等），惰性覆盖为启发式近似；已收紧 ++/-- 后紧跟除号吞同行注释的形状（正则允许集去 + 与 -，钉测在册），残余罕见形以逐字回填不破源码兜底
- 评审 G-2 已补齐：行/块注释后与 TplExpr 花括号、模板 ${ 入口四处 prev_sig 重置（行首感/开括号感），不再读陈旧前文
- 评审 G-3 已修：占位冲撞文案按词法族分流（r# 预处理/注释占位）
