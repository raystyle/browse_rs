# gate-verdict:门禁判定的退出码纪律

> 闸门记录(轮 0,2026-10-10 人裁接受):门禁当轮实跑无回归(fmt/clippy/test-lib/surface/aidoc-check 退出码全 0);点名义务「门禁判定纪律散在 memory 无标准页」从散注到标准页;知识底座 [[R101-pattern-gate-verdict-pipe-swallows-red]](diary trace 四件)。促成本技能的模式页:knowledge/references/R101。

## When to Apply

- 跑任何门禁(cargo test、check.py、CI 脚本)并要给出过/败结论
- 长输出命令的判定(构建、回归、验收脚本)
- 复查日志或输出文件来判定「这一轮是否通过」

## When NOT to Apply

- 页内求值与交互探索(browse --js、REPL):即时读输出即可,无判定语义
- 写代码与重构批:本技能只管「怎么判」,不管「怎么改」
- 单纯查看内容(读文档、grep 找定义):没有过/败结论就没有吞红面

## 步骤

1. 判定命令一律退出码形:`cmd > log 2>&1; echo $?`,看打印的退出码再下结论(0 过,非 0 败)
2. 禁止把判定寄生在管道尾:不用 `cmd | tail`、`cmd && echo ok`、`cmd | grep 关键词` 作为判定
3. 需要看输出细节时,分两步:先重定向落盘拿退出码,再独立地读该日志(读文件不过判定)
4. 日志判定只认**本轮新写**的文件:上轮残留日志里 grep 到关键词不算本轮通过
5. 回执带退出码原文(例「clippy=0」),不转述「看起来过了」
