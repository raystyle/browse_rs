# REQ-018：注释区 Jinja 惰性化与三层正交文档

## Scenario

总台 r# 增益面实测对齐（2026-10-02）确认两层增益与混合件零影响后问「需要修复优化么」；工位判定无必修缺陷、建议两项小优化（注释区 Jinja 惰性化：战役台坑一实战实证；format! 三层正交文档句：坑二误解面），总台令「优化」「优化 review 封一个 0.1 小版本」。

## Criteria

- [x] 注释区（`//` 行注释与 `/* */` 块注释，含表达式内）整段占位抽取进「抽取、渲染、回填」同道：逐字回填（含定界符）、行数不变、EOF 无换行与未闭合块注释整段惰性
- [x] 注释内 `{{ }}`/字面 `{% raw %}` 标签/`r#` 形文本：不渲染、不替换、不进未填键点名扫描
- [x] 免渲染道（无 --vars）幂等：daemon run() 入口重写对注释是逐字回填空转
- [x] 三层正交文档句入 http-api r# 节（Jinja 层/format! 层/转义层）
- [x] 测试：rawstr 注释惰性双件 + CLI 渲染道一件 + 既有全族回归绿

## Notes

- 行为收窄判 minor（0.29.0）：注释从「可渲染」变「字面」：无在册用例依赖注释内替换（战役台与总台确认迁移语义按「要渲染的留普通串、要字面的进注释或 r#」）
- 设计延续：注释惰性化与 r# 免渲染同一机制（占位抽取回填），非第二套管线
