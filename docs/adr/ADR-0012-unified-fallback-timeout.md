# ADR-0012：统一兜底超时（标准、命令、函数三件）

## Context

超时面沿革分叉：方言 wait 族有 #51 秒口径（>=1000 按毫秒误写换算告警、封顶 600 秒），rn 面整体上界 45 秒（v0.26.1 战役台诉求，env 形 BROWSE_RUNE_TIMEOUT），/eval 300 秒（REQ-016 契约），fetch 自带 `--timeout`（裸解析），rn 侧已有 OpProbe 在飞面探针与结构化超时回执但 /eval 无卡点面。用户令统一（2026-10-03）：形成统一标准、统一命令、统一函数的兜底超时；其作用是兜底硬指标，与事件/条件等待窗不冲突（命名区别）；默认 60 秒可自定义。

## Decision

- **统一标准（三层正交）**：兜底硬指标（执行层，到期即结构化退出，统一缺省 **60 秒**）与等待窗（wait 族的命中型参数，自命中即返、到窗尽是正常分支）是两类概念，命名恒区别（timeout 字样专属兜底界；等待参数随函数）。调用层内建界不变（CDP 单调用 30 秒、同源腿 60 秒、引擎忙排队 10 秒）。
- **统一命令**：全局旗标 `--timeout <s>`（尾置合法），作用于两执行道（`browse rune` 与 `--js`/方言求值道），请求级覆写 env 缺省（`BROWSE_RUNE_TIMEOUT`/`BROWSE_EVAL_TIMEOUT`，env 是实例内缺省不再是全局定格）；`browse fetch` 的 `--timeout` 收编同一守卫。值经统一秒口径守卫（>=1000 按毫秒误写换算并告警）。
- **统一函数**：单一换算器 `js_host::secs_to_ms`（#51 口径公开为全域唯一实现，旗标、env 旋钮、方言 wait 族共用）+ 在飞面探针统一（/eval 侧 JsHost `current_op` 探针挂在 `call_global` 收口，片段道与编程道同覆盖；/rune 侧沿用 OpProbe）+ 结构化超时回执同形（两道都回 `{op, elapsed_ms, bound_s}` 加卡点 CTA，/eval 新增此面）。
- 缺省沿革收口：rune 45、eval 300 统一为 60（用户终裁；中途拟 180 后收敛 60）。

## Consequences

- 好：一道心智（timeout=兜底硬界 60 秒缺省，--timeout 即调）；超时回执全域带卡点（哪个函数/调用面没完成直接点名），上层 agent 解析 stderr 一行 JSON 即可换道
- 坏：缺省变更两面（rune 45 至 60 放宽、eval 300 至 60 收紧；长跑方言片段显式给 --timeout 或调 env）；daemon 级语义从「实例内同界」改为「env 缺省可逐次覆写」，既有文档口径要同步
- 缓解：收紧面只影响超 60 秒的无参长跑（此前 300 秒内静默跑完的现在到期退出，回执带卡点与 CTA）；env 旋钮与旗标都是显式道

## Alternatives

- 统一到 180 秒（用户中途口径）：被否，终裁 60 秒（更紧的兜底语义，等待窗不受影响）
- wait 族参数并入 timeout 口径改名：被否。等待窗是命中型语义（到窗尽是正常分支不是失败），兜底界是硬退出语义，两者正交且已命名区别
- /eval 不加卡点面（维持裸超时文案）：被否，统一函数要求两道回执同形
